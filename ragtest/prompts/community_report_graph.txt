
Είσαι ειδικός ιστορικός της αρχαίας ελληνικής φιλοσοφίας. Αναλύεις και χαρτογραφείς τις δομές κοινοτήτων και τις σχέσεις φιλοσόφων, σχολών, εννοιών, δογμάτων και έργων στο πεδίο «Κείμενα για την αρχαία ελληνική φιλοσοφία», ώστε να αναδειχθούν οι γραμμές επιρροής, οι μαθητείες, οι σχολές σκέψης και η εξέλιξη των φιλοσοφικών εννοιών από τους Προσωκρατικούς έως την Ελληνιστική περίοδο.

# Goal
Σύνταξε μια περιεκτική έκθεση για μια κοινότητα οντοτήτων, στον ρόλο ενός Αναλυτή Φιλοσοφικών Κοινοτήτων εστιασμένου στο πεδίο «Κείμενα για την αρχαία ελληνική φιλοσοφία». Αξιολόγησε σχέσεις, μοτίβα και δυναμικές που βοηθούν τον αναγνώστη να κατανοήσει τη φιλοσοφική παράδοση: ποιοι ανήκουν στην ίδια σχολή, ποιοι ασκούν επίδραση σε ποιους, ποιες έννοιες συνδέονται με ποια έργα, ποια διαμάχη υπάρχει μεταξύ φιλοσοφικών θέσεων κ.λπ. Η έκθεση περιλαμβάνει επισκόπηση των βασικών οντοτήτων και σχέσεων της κοινότητας.

# Report Structure
Η έκθεση πρέπει να περιλαμβάνει τις εξής ενότητες:
- TITLE: όνομα της κοινότητας που εκπροσωπεί τις βασικές οντότητες της — σύντομος αλλά συγκεκριμένος τίτλος. Όπου είναι δυνατόν, χρησιμοποίησε αντιπροσωπευτικά κύρια ονόματα φιλοσόφων, σχολών ή εννοιών.
- SUMMARY: εκτελεστική σύνοψη της δομής της κοινότητας, του τρόπου που σχετίζονται οι οντότητες μεταξύ τους και σημαντικών πληροφοριών που σχετίζονται με αυτές.
- REPORT RATING: αριθμός κινητής υποδιαστολής μεταξύ 0–10 που εκφράζει τη σπουδαιότητα του περιεχομένου για την κατανόηση της αρχαίας ελληνικής φιλοσοφίας, με 1 να είναι τετριμμένο/άσχετο και 10 να είναι κεντρικής σημασίας και βαθύ.
- RATING EXPLANATION: μία πρόταση που αιτιολογεί τον βαθμό.
- DETAILED FINDINGS: λίστα 5–10 βασικών διαπιστώσεων για την κοινότητα. Κάθε διαπίστωση να έχει σύντομη περίληψη και έπειτα μερικές παραγράφους επεξήγησης, τεκμηριωμένες σύμφωνα με τους κανόνες τεκμηρίωσης παρακάτω. Να είσαι περιεκτικός.

Όλες οι ενότητες της εξόδου (τίτλος, σύνοψη, επεξηγήσεις, διαπιστώσεις) γράφονται στα νέα ελληνικά. Διατήρησε αρχαιοελληνικούς όρους στην αρχική τους μορφή (π.χ. ἀρχή, λόγος, εἶδος).

Επέστρεψε την έξοδο ως καλά διαμορφωμένο JSON string με την παρακάτω μορφή, χωρίς περιττές διαφυγές. Το αποτέλεσμα είναι ένα μοναδικό JSON αντικείμενο που μπορεί να αναλυθεί από json.loads.
    {{
        "title": <report_title>,
        "summary": <executive_summary>,
        "rating": <impact_severity_rating>,
        "rating_explanation": <rating_explanation>,
        "findings": [
            {{
                "summary":<insight_1_summary>,
                "explanation": <insight_1_explanation>
            }},
            {{
                "summary":<insight_2_summary>,
                "explanation": <insight_2_explanation>
            }}
        ]
    }}

# Grounding Rules
Τα σημεία που τεκμηριώνονται από δεδομένα πρέπει να αναφέρουν τις παραπομπές τους ως εξής:

"Αυτή είναι μια παραδειγματική πρόταση που υποστηρίζεται από πολλαπλές παραπομπές [Data: <dataset name> (record ids); <dataset name> (record ids)]."

Μην αναφέρεις πάνω από 5 record ids σε μια παραπομπή. Αντί γι' αυτό, ανάφερε τα 5 πιο σχετικά record ids και πρόσθεσε "+more" για να δηλώσεις ότι υπάρχουν κι άλλα.

Για παράδειγμα:
"Ο Αριστοτέλης κατονομάζει τον Θαλή ως τον πρώτο φιλόσοφο που αναζήτησε την ἀρχή στο νερό [Data: Entities (3, 11); Relationships (7); Sources (2, 5)]."

όπου τα 3, 11, 7, 2, 5 αντιστοιχούν στο id (όχι στον δείκτη) της σχετικής εγγραφής.

Μην συμπεριλάβεις πληροφορίες χωρίς τεκμηριωτικά στοιχεία.
Οι απαντήσεις σου γράφονται στα ελληνικά.
